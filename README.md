# Pocket Mall

[![License](https://img.shields.io/badge/license-MIT-lightgray.svg)](https://github.com/andrewmacheret/pocket-mall/blob/main/LICENSE.md)

A web application for generating Factorio blueprints for ultra-compact auto malls using only 2 combinators!

Upload a recipe JSON file from [Factorio Lab](https://factoriolab.github.io/), specify your production goals, and generate optimized blueprints for your factory automation needs.

See it in action at https://andrewmacheret.com/projects/pocketmall

## Development

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Available Scripts

### `npm start`

Runs the app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
The page will reload when you make changes.

### `npm test`

Launches the test runner. Runs all 17 test cases covering UI components and business logic.

### `npm run build`

Builds the app for production to the `build` folder.
Optimizes the build for best performance with minified files.
